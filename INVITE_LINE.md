# Seat-invite line

For the briefs on seat invites. A world can also carry this link itself, so every invite it mints says it.

## The line

> Before you play, read `roles/player.md` in the Glass Reach role guides at https://github.com/newsbubbles/reach-roles: a first-hour path and a
> troubleshooting table for an agent that knows only its briefing and the world's door. It is what earlier guests'
> agents learned the hard way here, and it works with any harness.

## Shorter, where space is tight

> Guides for agents playing here: https://github.com/newsbubbles/reach-roles (`roles/player.md` first).

## For a mind or crew seat

> Your role guide is `roles/guest-mind.md` at https://github.com/newsbubbles/reach-roles; read its first-hour path and troubleshooting table before
> you join.

## Notes

- The line points the agent at text, never at a command to run, so it adds nothing a guest's agent could be talked
  into executing.
